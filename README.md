# 202361290-SarahAlsuwaybi-assignment1 — Personal Portfolio

A simple, responsive personal portfolio website built with HTML, CSS, and JavaScript, as the foundation for a professional portfolio.

## Live Demo

🔗 [View the live site] (https://github.com/SARAH-ALSUWAYBI/202361290-SarahAlsuw-aybi-assignment1.git)
## Features

- **About Me** — a short introduction, tagline, and profile photo
- **Projects** — two featured projects with images, descriptions, and a link to source code
- **Contact** — a form (Name, Email, Message) for visitors to reach out
- **Responsive design** — adapts cleanly to desktop, tablet, and mobile screen sizes using CSS Flexbox/Grid
- **Smooth scrolling** — clicking a nav link (About / Projects / Contact) smoothly scrolls to that section instead of jumping instantly

## Tech Stack

- CSS
- JavaScript
